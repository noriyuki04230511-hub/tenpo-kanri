# tenpo-kanri（株式会社3k 店舗管理システム）

各卓のiPadを起点に、出勤・受付・ヒアリング・接客・成約後の手続き・アンケート・予約を記録する店舗運営アプリ。
既存システム（ALL MOBILE）とは別のシステムで、既存システムからは店舗・スタッフ・シフトを読み取るだけ。

- `prototype/index.html` … 見本データだけで動く画面試作 v0.5（デザイン版 v2 ＋ 予約）

- `docs/existing-system-readonly-window.sql` … 既存システム側に作った読み取り専用の窓の記録と、取り消しの文
